This appendix maps the implemented modules to their responsibilities. The repository source files are authoritative; copied code excerpts are omitted to avoid drift.

3.11.2 Backend and database

FileImplemented responsibility
backend/server.jsExpress API, registration/login/logout, JWT authentication, dashboard, progression, grading, notifications, and SQLite initialization.
backend/content-store.jsCreates and seeds content tables and serves database-backed catalog, lesson, and quiz data.

The SQLite schema has 11 tables: users, learning_progress, quiz_attempts, notifications, revoked_tokens, activity_attempts, assessment_attempts, algorithms, lessons, quizzes, and quiz_questions.

3.11.3 Implemented API routes

  • Public: GET /api/health, GET /api/algorithms, GET /api/algorithm-groups.js, POST /api/register, and POST /api/login.
  • Authenticated: POST /api/logout, GET /api/dashboard, lesson start/concept/activity/daily-quiz routes under /api/learning/:day, assessment read/submit routes under /api/assessments/:assessmentId, and notification read route PATCH /api/notifications/:id/read.

3.11.4 Authentication, configuration, and test evidence

Passwords are hashed with bcryptjs. JWTs use JWT_SECRET, expire after seven days, and are checked against SHA-256 token hashes in revoked_tokens. Production startup requires an explicitly configured secret. SQLite queries are parameterized and foreign keys are enabled.

Root package.json provides Vite scripts; backend/package.json provides the backend start, watch, and test scripts. See the README for installation and startup instructions. The current backend test result is documented in the final report and README.
