CHAPTER II

SYNOPSIS OF THE PROJECT

2.1 Problem Statement

Data Structures and Algorithms (DSA) form the foundational backbone of computer science and professional software engineering. However, novice learners consistently experience high cognitive friction when studying algorithms solely through static textbooks, monolithic code listings, or lecture pseudocode. Traditional static illustrations fail to communicate the runtime state transformations of mutable data structures (e.g., swapping array elements, pointer redirections in linked lists, tree balancing, or graph edge relaxations).

Furthermore, theoretical comprehension does not automatically yield programming fluency. Learners frequently lack an integrated environment where they can inspect conceptual visualizations, immediately write code in an online IDE, and validate their mastery through progressive, graded assessments. Algorithm Hub bridges this gap by providing an integrated, interactive pedagogical suite with animated visualizations, an online multi-language code compiler, and an authenticated 30-day sequential curriculum with automated grading.

2.2 Objectives and Scope

2.2.1 Objectives

  • Systematic Algorithm Taxonomy: To catalog 93 classic and advanced algorithms across 12 distinct categories with detailed pseudocode, invariant explanations, and asymptotic bounds.
  • Interactive Visual Execution: To develop interactive animation visualizers (Sorting, Searching, Trees, Graphs) allowing variable speeds, step-by-step frame inspection, and random input generation.
  • Integrated Multi-Language Practice Lab: To embed a compiler workspace supporting C++, Java, Python, and JavaScript, leveraging remote containerized compiler APIs.
  • Sequential 30-Day Guided Learning Track: To design a pedagogical curriculum requiring students to progress sequentially through 6 daily stages (Learn → Understand → Visualize → Practice → Quiz → Review).
  • Automated Assessment & Verification: To author 300 daily quiz questions and 4 milestone assessments (Days 7, 14, 21, 30) evaluated by a backend grading engine requiring ≥ 70% passing threshold.
  • Secure User Authentication & Persistence: To implement bcrypt password hashing and 7-day signed JWT tokens with server-side revocation on logout.

2.2.2 Scope

Algorithm Hub is engineered for undergraduate computer science students, competitive programming aspirants, and software engineering interviewees. The platform features an ultra-responsive frontend built with HTML5, CSS3, ES6 JavaScript, and Vite, paired with a lightweight Node.js/Express REST backend backed by SQLite persistence. The application operates seamlessly in local and private LAN educational environments.

2.3 Process Description

  1. User Registration & Session Initiation: Learner registers with name, email, and password. The system stores salted bcrypt hashes and returns a signed JWT.
  2. Catalog & Knowledge Retrieval: Learner browses algorithms categorized by complexity and data structure. Detailed walkthroughs and time/space complexities are rendered.
  3. Visual Experimentation: The learner steps through visual algorithms on dynamic canvases, inspecting comparisons and pointer updates.
  4. Practice Lab Code Execution: Learner enters solutions in the editor; the client relays code to the Wandbox remote compiler API, displaying stdout/stderr in real time.
  5. Curriculum Progression & Activity Matching: In the 30-day dashboard, the learner completes the daily concept review and submits a computed output that must match a server-side test case.
  6. Graded Quiz & Milestone Assessment: The learner answers 10 multiple-choice questions. Achieving ≥ 70% marks the daily quiz passed. On milestone days (7, 14, 21, 30), a separate comprehensive assessment unlocks and must also be cleared to unlock subsequent days.

Algorithm Hub provides a unified, interactive platform for computer science education. 3.2 Theoretical Background

3.2.1 Algorithms and Complexity Analysis

An algorithm is a finite sequence of unambiguous instructions solving a specific computational problem. Efficiency is quantified using asymptotic notation (Big O, Big Ω, Big Θ). Algorithm Hub validates time complexity across best, average, and worst cases, alongside auxiliary space complexity.

3.2.2 Technology Stack Justification

  • Frontend (HTML5, Vanilla CSS3, ES6 JavaScript, Vite): Ensures zero-framework overhead, sub-millisecond DOM manipulation for visualizer frame rendering, and instant hot-module replacement during development.
  • Backend (Node.js & Express): Provides asynchronous, non-blocking I/O ideal for concurrent API requests, authentication checking, and test grading.
  • Database (SQLite3): A self-contained, serverless zero-configuration relational database engine offering ACID compliance and parameterized queries without external database server overhead.
  • Security Layer (JWT & bcryptjs): Employs 10-round bcrypt salted password hashing and 7-day cryptographic JSON Web Tokens with a server-side revocation list.
  • Compilation Relay (Wandbox API): Allows browser-based execution of C++, Java, Python, and JavaScript without requiring local compiler installations.

3.3 Survey of Literature and Research Analysis

Extensive educational research confirms that interactive algorithm visualization significantly enhances conceptual retention compared to static text. Traditional textbooks provide rigorous theoretical proofs but fail to represent runtime memory dynamics. While platforms like LeetCode and HackerRank offer robust automated grading, they cater primarily to assessment rather than beginner pedagogy. Algorithm Hub combines the strengths of educational visualizers (like VisuAlgo) with the guided discipline of structured learning curricula and live code compilation.

3.9 Methodology Used for Testing

To verify correctness, security, and performance, Algorithm Hub was validated using a multi-tier testing strategy combining automated backend test suites, database integrity audits, and manual cross-browser usability checks.

  • Automated Unit & Integration Testing: Built with Node.js built-in test runner (`node:test`) and assert library. Tests initialize an isolated temporary SQLite database, verifying registration rejection, password hashing, token validation, sequential unlocking from Day 1 to Day 30, and token revocation on logout.
  • Security & Authentication Testing: Validated that protected API routes (`/api/dashboard`, `/api/learning/:day`) reject missing, expired, malformed, or revoked JWT tokens with HTTP 401 Unauthorized status. Tested SQL injection protection via parameterized queries.
  • Curriculum & Grader Verification: Audited all 300 daily quiz questions and 40 milestone questions to ensure four distinct choices per item, unique IDs, hints, explanations, and exact grading at 70% threshold.
  • Usability & Cross-Browser Compatibility: Verified responsive rendering across Google Chrome, Microsoft Edge, and Mozilla Firefox at viewports from 375px (mobile) to 1920px (desktop).

import express from 'express';
import cors from 'cors';
import jwt from 'jsonwebtoken';
import bcrypt from 'bcryptjs';
import sqlite3 from 'sqlite3';
import { createHash } from 'node:crypto';
import { curriculum, publicDay } from './curriculum.js';
import { assessments } from './quiz-bank.js';

const app = express();
const db = new sqlite3.Database(process.env.DB_PATH || './data/algorithm-hub.db');
const JWT_SECRET = process.env.JWT_SECRET || 'development-secret-key';

app.use(cors({ origin: true, credentials: true }));
app.use(express.json({ limit: '100kb' }));

// Helper: Promise-based SQLite queries
const runDb = (sql, params = []) => new Promise((resolve, reject) => {
  db.run(sql, params, function (err) {
    if (err) reject(err); else resolve({ id: this.lastID, changes: this.changes });
  });
});
const getDb = (sql, params = []) => new Promise((resolve, reject) => {
  db.get(sql, params, (err, row) => { if (err) reject(err); else resolve(row); });
});

// Authentication Middleware with Token Revocation Check
const requireAuth = async (req, res, next) => {
  const authHeader = req.get('authorization') || '';
  const token = authHeader.startsWith('Bearer ') ? authHeader.slice(7) : '';
  if (!token) return res.status(401).json({ message: 'Sign in to access your dashboard.' });

  try {
    const payload = jwt.verify(token, JWT_SECRET);
    const tokenHash = createHash('sha256').update(token).digest('hex');
    const isRevoked = await getDb('SELECT tokenHash FROM revoked_tokens WHERE tokenHash = ?', [tokenHash]);
    if (isRevoked) return res.status(401).json({ message: 'Session signed out. Please sign in again.' });

    const user = await getDb('SELECT id, name, email FROM users WHERE id = ?', [payload.id]);
    if (!user) return res.status(401).json({ message: 'User session invalid.' });

    req.user = user;
    req.token = token;
    next();
  } catch (err) {
    return res.status(401).json({ message: 'Session expired or invalid.' });
  }
};

// User Registration Endpoint
app.post('/api/register', async (req, res) => {
  const { name, email, password } = req.body;
  if (!name || !email || !password) return res.status(400).json({ message: 'All fields required.' });

  const existing = await getDb('SELECT id FROM users WHERE email = ?', [email.toLowerCase().trim()]);
  if (existing) return res.status(409).json({ message: 'Email already registered.' });

  const hashedPassword = await bcrypt.hash(password, 10);
  const userId = 'usr_' + Date.now();
  await runDb('INSERT INTO users (id, name, email, password, createdAt) VALUES (?, ?, ?, ?, ?)',
    [userId, name.trim(), email.toLowerCase().trim(), hashedPassword, new Date().toISOString()]);

  const token = jwt.sign({ id: userId, email }, JWT_SECRET, { expiresIn: '7d' });
  res.status(201).json({ token, user: { id: userId, name, email } });
});

3.11.2 Curriculum Progression & Grading Engine (`backend/server.js`)

// Daily Quiz Submission & Grading Endpoint
app.post('/api/learning/:day/quiz', requireAuth, async (req, res) => {
  const dayNum = parseInt(req.params.day, 10);
  const { answers } = req.body; // Array of submitted option indices

  const dayData = curriculum.find(d => d.day === dayNum);
  if (!dayData || !answers) return res.status(400).json({ message: 'Invalid quiz payload.' });

  // Evaluate against authored answer keys
  let correctCount = 0;
  dayData.quiz.forEach((q, idx) => {
    if (answers[idx] === q.correctAnswer) correctCount++;
  });

  const scorePercentage = Math.round((correctCount / dayData.quiz.length) * 100);
  const isPassed = scorePercentage >= 70;

  // Record attempt in quiz_attempts table
  const attemptId = 'qa_' + Date.now();
  await runDb('INSERT INTO quiz_attempts (id, userId, day, score, passed, submittedAt) VALUES (?, ?, ?, ?, ?, ?)',
    [attemptId, req.user.id, dayNum, scorePercentage, isPassed ? 1 : 0, new Date().toISOString()]);

  // Check if milestone day requirement applies (Days 7, 14, 21, 30)
  const isMilestone = [7, 14, 21, 30].includes(dayNum);
  let milestonePassed = true;
  if (isMilestone) {
    const assessRow = await getDb(
      'SELECT passed FROM assessment_attempts WHERE userId = ? AND assessmentId = ? AND passed = 1',
      [req.user.id, dayData.milestoneAssessmentId]
    );
    milestonePassed = !!assessRow;
  }

  // Update learning_progress record
  const dayCompleted = isPassed && milestonePassed;
  await runDb(`
    UPDATE learning_progress 
    SET dailyQuizPassed = MAX(dailyQuizPassed, ?),
        latestScore = ?,
        completedAt = CASE WHEN ? = 1 THEN COALESCE(completedAt, ?) ELSE completedAt END
    WHERE userId = ? AND day = ?
  `, [isPassed ? 1 : 0, scorePercentage, dayCompleted ? 1 : 0, new Date().toISOString(), req.user.id, dayNum]);

  // If day completed, unlock Day N+1 and notify user
  if (dayCompleted && dayNum < 30) {
    await runDb(`
      INSERT OR IGNORE INTO learning_progress (userId, day, startedAt)
      VALUES (?, ?, ?)
    `, [req.user.id, dayNum + 1, new Date().toISOString()]);

    const notifKey = `${req.user.id}_day${dayNum}_complete`;
    await runDb(`
      INSERT OR IGNORE INTO notifications (id, notificationKey, userId, day, message, createdAt)
      VALUES (?, ?, ?, ?, ?, ?)
    `, ['notif_' + Date.now(), notifKey, req.user.id, dayNum,
        `Congratulations! You completed Day ${dayNum}. Day ${dayNum + 1} is now unlocked.`, new Date().toISOString()]);
  }

  res.json({ score: scorePercentage, passed: isPassed, dayCompleted });
});

3.11.3 Interactive Visualizer Core Animation Loop (`visualizer-core.js`)

export class VisualizerCore {
  constructor(canvasContainer, options = {}) {
    this.container = typeof canvasContainer === 'string' 
      ? document.querySelector(canvasContainer) 
      : canvasContainer;
    this.speed = options.speed || 300;
    this.stateArray = [];
    this.historyFrames = [];
    this.currentFrameIdx = 0;
    this.isPlaying = false;
    this.timer = null;
  }

  setSpeed(ms) {
    this.speed = Math.max(10, Math.min(2000, ms));
  }

  loadArray(arr) {
    this.stateArray = [...arr];
    this.historyFrames = [];
    this.currentFrameIdx = 0;
    this.renderCurrentState();
  }

  pushFrame(snapshot) {
    this.historyFrames.push({
      array: [...snapshot.array],
      highlightIndices: [...(snapshot.highlights || [])],
      swappingIndices: [...(snapshot.swaps || [])],
      sortedIndices: [...(snapshot.sorted || [])],
      codeLine: snapshot.line || null
    });
  }

  play() {
    if (this.isPlaying) return;
    this.isPlaying = true;
    this.runLoop();
  }

  pause() {
    this.isPlaying = false;
    clearTimeout(this.timer);
  }

  stepForward() {
    if (this.currentFrameIdx < this.historyFrames.length - 1) {
      this.currentFrameIdx++;
      this.renderFrame(this.historyFrames[this.currentFrameIdx]);
    }
  }

  stepBackward() {
    if (this.currentFrameIdx > 0) {
      this.currentFrameIdx--;
      this.renderFrame(this.historyFrames[this.currentFrameIdx]);
    }
  }

  runLoop() {
    if (!this.isPlaying) return;
    if (this.currentFrameIdx < this.historyFrames.length - 1) {
      this.stepForward();
      this.timer = setTimeout(() => this.runLoop(), this.speed);
    } else {
      this.pause();
    }
  }

  renderFrame(frame) {
    if (!frame || !this.container) return;
    this.container.innerHTML = '';
    const maxVal = Math.max(...frame.array, 1);

    frame.array.forEach((val, idx) => {
      const bar = document.createElement('div');
      bar.className = 'visualizer-bar';
      bar.style.height = `${(val / maxVal) * 100}%`;
      
      if (frame.sortedIndices.includes(idx)) bar.classList.add('is-sorted');
      else if (frame.swappingIndices.includes(idx)) bar.classList.add('is-swapping');
      else if (frame.highlightIndices.includes(idx)) bar.classList.add('is-comparing');

      const label = document.createElement('span');
      label.innerText = val;
      bar.appendChild(label);
      this.container.appendChild(bar);
    });
  }
}

3.11.4 Practice Lab Remote Compiler Relay Client (`practice-app.js`)

// Wandbox Remote Compiler Client Integration
export class PracticeCompilerClient {
  constructor() {
    this.apiEndpoint = 'https://wandbox.org/api/compile.json';
    this.compilerMap = {
      cpp: 'gcc-head',
      java: 'openjdk-head',
      python: 'cpython-head',
      javascript: 'nodejs-head'
    };
  }

  async executeCode(language, sourceCode, stdinInput = '') {
    const compiler = this.compilerMap[language];
    if (!compiler) throw new Error('Unsupported programming language: ' + language);

    const payload = {
      compiler: compiler,
      code: sourceCode,
      stdin: stdinInput,
      'compiler-option-raw': language === 'cpp' ? '-O2\n-std=c++20' : ''
    };

    const startTime = performance.now();
    try {
      const response = await fetch(this.apiEndpoint, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(payload)
      });

      if (!response.ok) {
        throw new Error(`Compiler API returned HTTP ${response.status}`);
      }

      const result = await response.json();
      const elapsedMs = Math.round(performance.now() - startTime);

      return {
        status: result.status === '0' ? 'SUCCESS' : 'RUNTIME_ERROR',
        stdout: result.program_output || result.program_message || '',
        stderr: result.compiler_error || result.program_error || '',
        executionTimeMs: elapsedMs
      };
    } catch (error) {
      return {
        status: 'CONNECTION_FAILURE',
        stdout: '',
        stderr: 'Failed to contact compilation service: ' + error.message,
        executionTimeMs: Math.round(performance.now() - startTime)
      };
    }
  }
}

CONCLUSION

The Algorithm Hub project successfully delivers an interactive, web-based platform for computer science education that solves the pedagogical limitations of static textbooks. By integrating animated visualizers, an online multi-language compiler, and a structured 30-day curriculum with automated server-side grading, the platform provides an engaging and disciplined environment for learning data structures and algorithms.

The project successfully fulfilled all foundational requirements: (1) A categorized catalog of 93 algorithms with time/space complexities; (2) Interactive visualizers for sorting and graph traversals; (3) A browser-based IDE communicating with the Wandbox remote compiler; (4) An authenticated student dashboard enforcing 6 sequential stages per day; (5) 300 daily quiz questions and 4 milestone assessments graded at a 70% threshold; (6) An SQLite database enforcing relational integrity, password hashing, and token revocation.

In conclusion, Algorithm Hub demonstrates the practical application of full-stack web engineering, database normalization, asynchronous API design, and educational software design, providing an effective educational tool for aspiring software engineers.
