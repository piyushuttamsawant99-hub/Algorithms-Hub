TIME & SPACE

Complexity Analysis.

Formal asymptotic bounds and resource consumption breakdown.

BEST CASE O(1)

Target is located at the first midpoint calculation.

AVERAGE CASE O(log n)

Each step cuts search space in half, requiring ~log2(n) comparisons.

WORST CASE O(log n)

Search narrows down to a single element before finding or exhausting.

SPACE COMPLEXITY O(1)

Iterative version uses O(1) auxiliary space.

Algorithmic Properties

Paradigm: Divide and Conquer
In-Place: Yes
Stable Sort: N/A
Data Structure: Sorted Array

Advantages

  • Extremely fast logarithmic time O(log n)
  • Minimal space overhead O(1)
  • Ideal for large read-heavy datasets

Limitations

  • Requires array to be pre-sorted
  • Inefficient for linked lists without random access indexing
