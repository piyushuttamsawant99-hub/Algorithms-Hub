Bubble Sort

Repeatedly compares adjacent elements and swaps them when they are in the wrong order.

BEST O(n)
AVERAGE O(n²)
WORST O(n²)
SPACE O(1)
PSEUDOCODE LOGIC 
for each element
    compare adjacent values
    if left > right
        swap them
repeat until sorted
